# Student Dropout Analysis Dashboard

## Overview

The Student Dropout Analysis Dashboard is a Business Intelligence project developed using Power BI to analyze student engagement, retention, and dropout patterns in an EdTech platform.

The dashboard helps educational institutions identify at-risk students, understand learner behavior, and improve retention through data-driven decision-making.

## Problem Statement

Student dropout is a major concern for educational institutions and online learning platforms. This project analyzes student activity and performance data to identify factors that contribute to student disengagement and dropout.

## Objectives

* Analyze student engagement levels.
* Monitor course completion rates.
* Identify students at risk of dropping out.
* Evaluate retention across different cohorts.
* Understand demographic factors affecting dropout rates.

## Dataset

The dataset contains information about students and their learning activities, including:

* Student ID
* Age
* Region
* Enrollment Date
* Exam Season
* Courses Enrolled
* Completed Assignments
* Completion Rate
* Login Frequency
* Last Activity Days Ago
* Forum Posts Count
* Dropout Score
* Student Status

## Key Insights

* Lower login frequency is associated with higher dropout risk.
* Assignment completion significantly impacts student retention.
* Inactive students tend to have higher dropout scores.
* Cohort analysis helps identify retention challenges over time.
* Engagement metrics can support early dropout prediction.

## Business Value

* Improve student retention strategies
